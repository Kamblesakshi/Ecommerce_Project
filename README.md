\# E-Commerce Web Application



A full-stack E-Commerce web application built using \*\*Django REST Framework\*\* for the backend and \*\*React.js\*\* for the frontend.



The application provides product browsing, authentication, cart management, checkout, order tracking, wishlist management, and product reviews.



\## Features



\- User Registration and Login

\- JWT Authentication

\- Product Listing

\- Product Search

\- Category Filtering

\- Price Filtering

\- Product Details

\- Shopping Cart

\- Increase / Decrease Cart Quantity

\- Remove Cart Items

\- Checkout

\- Order Placement

\- My Orders

\- Wishlist

\- Product Reviews and Ratings

\- User Profile

\- Responsive UI

\- JWT Access Token Refresh



\## Technology Stack
